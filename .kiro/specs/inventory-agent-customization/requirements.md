# 要件ドキュメント

## はじめに

このドキュメントは、コアとスキルのインベントリ管理の改善、およびエージェントカスタマイズシステムの再設計に関する要件を定義します。

現在のシステムでは同一アイテムが複数存在する冗長な状態（例: バランスコアLv.1を2つ所持）が発生しています。これを改善し、アイテムの種類ごとにユニークに管理する仕組みへ移行します。また、既存の「3スロットに個別合成」方式を廃止し、「3エージェントのコア・スキル自由付け替え」方式に転換します。

## 要件

### 要件 1: コアインベントリのユニーク管理

**目的:** プレイヤーとして、コアを特性ごとに最大レベルのみ保持する管理方式を望む。これにより、インベントリが冗長にならず管理しやすくなる。

#### 受け入れ基準

1. インベントリシステムは、コアをCoreTypeIDごとにユニークに管理し、各タイプの取得済み最大レベルのみを保存する。
2. プレイヤーが新しいコアを取得したとき、インベントリシステムは新しいコアのレベルと該当CoreTypeIDの既存最大レベルを比較する。
3. 新しいコアのレベルが既存の最大レベルより高い場合、インベントリシステムは保存されている最大レベルを新しいレベルに更新する。
4. 新しいコアのレベルが既存の最大レベル以下の場合、インベントリシステムはインベントリを変更せずに新しいコアを破棄する。
5. インベントリシステムは、所有している全てのCoreTypeIDとその最大レベルを取得するメソッドを提供する。

### 要件 2: スキルインベントリのユニーク管理

**目的:** プレイヤーとして、スキルを種類ごとに保有状態とチェイン効果バリエーションを分離して管理する方式を望む。これにより、同じスキルの重複取得が無駄にならない。

#### 受け入れ基準

1. インベントリシステムは、スキルをTypeIDごとに管理し、保有状態（保有/未保有）とチェイン効果バリエーションを分離して追跡する。
2. プレイヤーがスキルを初めて取得したとき、インベントリシステムはそのTypeIDを保有済みとしてマークする。
3. インベントリシステムは、保有している各スキルTypeIDに対して、取得済みのチェイン効果バリエーションのコレクションを維持する。
4. プレイヤーが既に所持しているスキルを再取得したとき、インベントリシステムはそのTypeIDのコレクションに新しいチェイン効果バリエーションを追加する。
5. 取得したスキルにチェイン効果がない場合、インベントリシステムは保有状態のみを更新する。
6. インベントリシステムは、所有している全てのスキルTypeIDとその利用可能なチェイン効果バリエーションを一覧表示するメソッドを提供する。

### 要件 3: エージェントスロットシステム

**目的:** プレイヤーとして、3つの固定エージェントスロットを持つことを望む。これにより、バトルで使用するエージェント構成を管理できる。

#### 受け入れ基準

1. エージェントシステムは、バトル構成用に正確に3つのエージェントスロットを提供する。
2. エージェントシステムは、各スロットが独立したコアとスキルの構成を持つことを許可する。
3. エージェントスロットにコアが未設定の間、エージェントシステムはそのスロットを空でバトルに使用不可として扱う。
4. エージェントシステムは、ゲームセッション間でエージェントスロットの構成を永続化する。

### 要件 4: エージェントコア付け替え

**目的:** プレイヤーとして、エージェントスロットに自由にコアを付け替えることを望む。これにより、戦略に応じてエージェント構成を変更できる。

#### 受け入れ基準

1. プレイヤーがエージェントスロットにコアを設定するとき、エージェントシステムは指定されたCoreTypeIDとレベルをそのスロットに設定する。
2. エージェントシステムは、同じCoreTypeIDを複数のエージェントスロットに同時に設定することを許可する。
3. プレイヤーがコアを変更するとき、エージェントシステムは新しいコアに基づいてエージェントのレベルと基本ステータスを再計算する。
4. コアが変更されたとき、エージェントシステムはスキルの互換性を検証し、互換性のないスキルをスロットから削除する。
5. エージェントシステムは、プレイヤーのインベントリに存在する任意のCoreTypeIDを、取得済み最大レベル以下の任意のレベルで選択することを許可する。

### 要件 5: エージェントスキル付け替え

**目的:** プレイヤーとして、エージェントスロットに自由にスキルを付け替えることを望む。これにより、スキル構成をカスタマイズできる。

#### 受け入れ基準

1. エージェントシステムは、エージェントスロットごとに4つのスキルスロットを提供する。
2. プレイヤーがスキルスロットにスキルを設定するとき、エージェントシステムは指定されたTypeIDとチェイン効果バリエーションをそのスロットに設定する。
3. エージェントシステムは、同じスキルTypeIDを全エージェントを通じて1つのスロットにのみ装備することを許可する。同じスキルを複数箇所に装備することはできない。
4. スキルを設定するとき、エージェントシステムはインベントリに保有しているスキルを許可する（チェイン効果の有無は問わない）。
5. エージェントシステムは、タグマッチングに基づいてスキルがエージェントのコアと互換性があることを検証する。
6. スキルがコアの許可タグを持たない場合、エージェントシステムはそのスキルの装備を阻止する。

### 要件 6: チェイン効果バリエーション選択

**目的:** プレイヤーとして、装備スキルのチェイン効果を所持バリエーションから選択することを望む。これにより、戦略に応じた効果を選べる。

#### 受け入れ基準

1. プレイヤーがスキルを装備するとき、エージェントシステムはそのTypeIDで利用可能なチェイン効果バリエーションを表示する。
2. エージェントシステムは、プレイヤーが利用可能なオプションから1つのチェイン効果バリエーションを選択することを許可する。
3. エージェントシステムは、同じチェイン効果バリエーションを複数のスキルスロットで選択することを許可する。
4. チェイン効果なしのスキルを装備するとき、エージェントシステムはチェイン効果バリエーション選択をスキップして装備を許可する。

### 要件 7: レベル選択によるエージェント調整

**目的:** プレイヤーとして、コア装備時に最大取得レベル以下の任意のレベルを選択することを望む。これにより、敵のレベルに合わせて調整できる。

#### 受け入れ基準

1. プレイヤーがコアを装備するとき、エージェントシステムはそのCoreTypeIDの1から取得済み最大レベルまでの任意のレベル選択を許可する。
2. エージェントシステムは、最大レベルではなく選択されたレベルに基づいてステータスを計算する。
3. レベルを変更するとき、エージェントシステムはそれに応じてエージェントのレベルと基本ステータスを再計算する。

### 要件 8: 既存エージェント合成システムの廃止

**目的:** 開発者として、既存のエージェント合成システムを廃止することを望む。これにより、新しいカスタマイズシステムに完全移行できる。

#### 受け入れ基準

1. システムは、コアとスキルから新しいエージェントインスタンスを作成するエージェント合成機能を削除する。
2. システムは、合成されたエージェントインスタンスを保存するAgentInventoryを削除する。
3. システムは、旧方式のセーブデータとの互換性を維持しない（旧セーブデータは存在しない前提）。

### 要件 9: 装備エージェントのバトル参照

**目的:** バトルシステムとして、新しいエージェントスロット構成を参照することを望む。これにより、バトル中に正しいエージェント情報を使用できる。

#### 受け入れ基準

1. バトルシステムは、装備エージェントリストの代わりに3つのエージェントスロットからエージェント構成を参照する。
2. バトル開始時、バトルシステムはスロット構成からAgentModelインスタンスを構築する。
3. バトルシステムは、コアが設定されているスロット（空でないスロット）のみをバトルに含める。
4. バトル中、エージェントシステムはスロット構成の変更を許可しない。

### 要件 10: インベントリUIの更新

**目的:** プレイヤーとして、新しいインベントリ管理方式を視覚的に確認することを望む。これにより、所持アイテムを把握できる。

#### 受け入れ基準

1. インベントリUIは、所有しているCoreTypeIDとその取得済み最大レベルを表示する。
2. インベントリUIは、所有しているスキルTypeIDと利用可能なチェイン効果バリエーションの数を表示する。
3. プレイヤーがスキルを選択したとき、UIはそのTypeIDで利用可能な全てのチェイン効果バリエーションを表示する。
4. インベントリUIは、現在エージェントスロットに装備されているアイテムを示す。

### 要件 11: エージェントカスタマイズUIの実装

**目的:** プレイヤーとして、エージェントスロットを直感的にカスタマイズすることを望む。これにより、戦略的なエージェント構成を組める。

#### 受け入れ基準

1. カスタマイズUIは、3つのエージェントスロットと現在の構成を表示する。
2. プレイヤーがスロットを選択したとき、UIはコアまたはスキルを変更するオプションを表示する。
3. コア選択モードでは、UIは所有しているCoreTypeIDとレベル選択オプションを表示する。
4. スキル選択モードでは、UIは現在のコアと互換性のあるスキルをフィルタリングし、チェイン効果バリエーションオプションを表示する。
5. UIは、選択前にスキルとコアの互換性を視覚的に示す。
6. UIは、スロットをクリアして空にすることを許可する。
