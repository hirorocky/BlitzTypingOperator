# Implementation Plan

## Task Overview

コアレベルシステムを廃止し、敵ランクベースの進行システムを導入するための実装タスクです。

---

## Tasks

- [x] 1. コアモデルからレベル概念を削除する

- [x] 1.1 (P) コアエンティティからレベルフィールドを削除し、ステータス計算を重みベースに変更する
  - コアモデルからLevelフィールドを削除する
  - ステータス計算式を「100 x コアの重み」に変更する
  - NewCoreWithTypeIDからlevel引数を削除する
  - 関連するコンストラクタとファクトリ関数を修正する
  - _Requirements: 1.1, 1.2, 2.1, 2.2, 2.3_

- [x] 1.2 (P) コアインベントリをTypeIDベースのフラグ管理に変更する
  - 保有データ構造をmap[string]bool（TypeID -> 保有フラグ）に変更する
  - 最大レベル追跡機能を削除する
  - GetOwnedCoresの戻り値を[]stringに変更する
  - AddCore/HasCoreをTypeIDのみで動作するように修正する
  - _Requirements: 1.3, 1.4_

- [x] 2. エージェントスロット管理のレベル依存を削除する

- [x] 2.1 スロットマネージャーからレベル引数と検証ロジックを削除する
  - SetCoreメソッドからlevel引数を削除する
  - レベル範囲検証ロジック（ErrLevelOutOfRange）を削除する
  - buildAgentFromSlotをレベルなしで動作するように修正する
  - コア保有チェックのみを残す
  - _Requirements: 1.1, 3.1_

- [x] 3. プレイヤーの最大HP管理を変更する

- [x] 3.1 (P) プレイヤーモデルの最大HP初期化と成長機能を実装する

  - IncreaseMaxHPメソッドを追加する
  - RecalculateHP（エージェントレベル依存）を削除する
  - PrepareForBattleでFullHealのみを実行するように変更する
  - _Requirements: 4.1, 4.2, 7.1, 9.1_

- [x] 4. 敵進行システムのドメインモデルを実装する

- [x] 4.1 (P) 敵タイプにランク情報を追加する

  - マスタデータ（enemies.json）にRankフィールドを追加する
  - デフォルトレベルを1として扱う
  - _Requirements: 5.1, 5.2, 6.4_

- [x] 4.2 (P) 敵撃破記録を管理するドメインモデルを新規作成する
  - EnemyDefeatRecordエンティティを作成する（撃破フラグ、最大撃破レベル）
  - EnemyProgressエンティティを作成する（現在ランク、撃破記録マップ）
  - 撃破記録とHP成長量計算のメソッドを実装する
  - 選択可能レベル範囲の計算メソッドを実装する
  - _Requirements: 6.1, 6.4, 6.5, 7.2, 7.3, 8.2, 8.3, 8.4, 9.2, 9.3_

- [ ] 5. 敵進行管理のユースケースを実装する

  - 現在ランクの敵リスト取得機能を実装する
  - 選択可能レベル範囲取得機能を実装する
  - 撃破記録とHP成長適用機能を実装する
  - ランク内全敵撃破チェック機能を実装する
