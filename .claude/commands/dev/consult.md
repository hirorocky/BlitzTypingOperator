# codex相談

## 概要
開発中の問題や判断に迷う点についてcodexに相談し、複数の視点から検討する。

## 実行ステップ

### 1. コンテキスト収集
相談内容に関連するコンテキストを自動収集する:
- `git diff` で現在の作業中の変更
- 関連するソースファイルの内容
- `docs/project/` に進行中のフィーチャーがあればその内容

### 2. codexに相談
収集したコンテキストと質問をcodexに送る:

```bash
codex exec --full-auto "以下の状況について相談です。\n\n質問: $ARGUMENTS\n\nコンテキスト:\n{収集した関連情報}\n\n技術的な観点からアドバイスをください。"
```

### 3. 比較検討
codexの回答を受けて:
- 自分の分析結果とcodexの意見を比較
- 一致している点と相違点を明示
- 総合的な判断を提示

## 出力形式
```
### codexの意見
{codexの回答を引用}

### 分析
{自分の分析とcodexの意見の比較}

### 推奨アクション
{総合判断に基づく推奨}
```

## 注意事項
- codexの提案を鵜呑みにせず、根拠を理解する
- 自分の分析結果と異なる場合は、双方の視点を比較検討する
- 最終的な判断は両者の意見を総合的に評価した上で下す
