# 使用可能な絵文字リスト

このプロジェクトのTUI（lipgloss）で安全に使用できる絵文字の一覧です。

## 根拠

Unicode公式データ（[emoji-data.txt](https://unicode.org/Public/15.1.0/ucd/emoji/emoji-data.txt)）から `Emoji_Presentation=Yes` の絵文字を全て抽出し、`go-runewidth` と `lipgloss.Width()` の両方で幅2として計算されるものをリストアップしています。

### 絵文字の分類

1. **Emoji_Presentation=Yes**（デフォルトで絵文字表示）
   - VS16なしで絵文字として表示される
   - 幅計算が安定している（このリストの対象）

2. **Emoji_Presentation=No**（デフォルトでテキスト表示）
   - VS16（U+FE0F）を付けて絵文字化する（例: ⚔️）
   - ライブラリ間で幅計算が不一致 → **使用禁止**

## 現在の対策

`inventory.go` の `normalizeInventoryIcon()` 関数で、VS16（U+FE0F）をVS15（U+FE0E、テキストスタイル）に置換することで幅を安定させています。ただし、この対策は絵文字の見た目がテキストスタイルに変わる場合があります。

新しい絵文字を追加する際は、上記の「安全に使える絵文字」から選択することを推奨します。
